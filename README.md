# Inova Trônica - Visão Computacional

## Objetivo

Desenvolver uma aplicação em Python capaz de enviar uma imagem para o Azure AI Vision e apresentar a descrição gerada pelo serviço de Visão Computacional.

## Tecnologias utilizadas

- Python
- Microsoft Azure AI Vision
- Azure Cloud Shell
- Azure AI Vision Image Analysis SDK

## Funcionamento

A aplicação recebe o caminho de uma imagem, envia o arquivo para o serviço Azure AI Vision e apresenta na tela a descrição gerada pelo serviço e o nível de confiança da análise.

## Exemplo de resultado

```text
Descrição da imagem:
a sunset over a city

Confiança da análise:
76.17%
